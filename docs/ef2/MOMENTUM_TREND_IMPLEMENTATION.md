# EF2 momentum and trend implementation

[EQ-147 #481](https://github.com/atulsrivas1/equity-features/issues/481), [EQ-148 #482](https://github.com/atulsrivas1/equity-features/issues/482) and [EQ-149 #483](https://github.com/atulsrivas1/equity-features/issues/483) library layer: the pure `intraday.momentum` producer family (config `intraday.momentum.v1`, convention group `ef2-conv1`) in `packages/intraday`. The frozen [contract](MOMENTUM_TREND_CONTRACT_PROPOSAL.md) (decisions DP1 to DP19, rulings Q1 to Q13 and its coordinator freeze) governs; this slice implements it and redefines nothing. The EF2 I/O mapping (#609), worker (#610) and release acceptance (#486) layers remain separate.

## Structure

`_momentum_config` (builder, closed decoder), `_momentum_registry` (own catalog and digest), `_momentum_math` (operands and Decimal120 recurrences) and `_momentum` (readiness, quality, evidence, dispatch). The R17 admission, context, `anchored_closes` and `true_ranges` arithmetic are reused unchanged. The two additive internal operand families are `directional_moves` ((+DM, -DM) for k = anchor+1..target, strict-greater-and-positive rule) and `rolling_extrema_runs` ((HH, LL, C) for consecutive window ends of one length; its last element is the R17 `high_extrema`/`low_extrema` operand for the same window). The R17 preparation record and catalog are untouched; the momentum catalog is separate (`describe_momentum`, `momentum_catalog_digest`), so `describe_intraday()` still lists exactly the eight accepted R17 IDs and its digest is unchanged.

## Mathematics and numeric policy

R17 policy: exact `Fraction` seeds, ordered recurrences in a fresh local Decimal context (precision 120, ROUND_HALF_EVEN, R17 traps), one guarded float64 conversion, exact zero published as `+0.0`, whole-call `OVERFLOW` on arithmetic failure. MACD runs the fast and slow chains independently from their own seeds and the signal over the ordered MACD observations (signal period 1 is the line exactly and the histogram `+0.0`; identical epoch closes give `+0.0` for all three). DMI smooths TR, +DM and -DM in the Wilder average form seeded by the mean, DI = 100 S_DM / S_TR, DX = 100 |S+ - S-| / (S+ + S-), ADX seeded at the first defined DX. Stochastic computes raw %K in the window including the current bar, %K and %D as simple means, and Williams %R as `-100 (HH - C) / (HH - LL)` directly. Zero ranges are undefined and propagate through smoothing as `not_applicable`/`zero_denominator`. Undefined DI/DX states are decided on exact inputs, never on rounded Decimal values.

## Readiness, counts and evidence

Every selected output owns its dependency slots and fields (MACD: close on every epoch slot; DMI: close, high, low on anchor..target-1 and high, low on the target, the anchor only when target = anchor; stochastic and Williams: per-output rolling windows with the close only on the last 1, `k_slowing` or `k_slowing + d_period - 1` slots), so an unrelated gap, null or absent column never blocks it. Status precedence is `missing_input`, `insufficient_history`, `incomplete_coverage`, `not_applicable`, `available`, with all applicable reasons in enum order; an absent delivery gives only `absent_input` with observed 0. Anchored outputs report `expected = max(seed, epoch slots)`, rolling outputs the window span; ADX applies the data-dependent `f + adx_period` rule only when every dependency slot is ready, DX is defined at the target and fewer than `adx_period` DX values exist. A `missing_input` output has no evidence rows; otherwise evidence follows R17 (consumed or knowledge-excluded supplied rows, `slot:<index>`, `completed_interval`, sorted by feature then slot, truncated to the result-wide `evidence_limit`).

## Points the contract leaves open (implemented conservatively)

1. **Fixture D04 input.** Its first bar has `low = 0`, which the shared BAR validator refuses (positive prices). The producer is unchanged; the fixture's expected values were checked on the same series translated by +10 (TR, DM, DI, DX and ADX are translation invariant). The fixture input should be corrected by the contract owner.
2. **`di_period = 1`.** The contract says the undefined DI/DX states are a prefix of the epoch, which holds for `di_period >= 2` (all weights positive) but not for 1, where the smoothed value is the current bar alone (a flat bar after a moving one gives `S_TR = 0` again). DI and DX at the target follow the literal definition (undefined iff the smoothed value is zero). An ADX chain that consumes an undefined DX (only possible for `di_period = 1`) is published `not_applicable`/`zero_denominator`; the contract does not say whether it should re-seed instead.
3. **Version label.** The contract mentions an unsupported "version label" yet lists no label parameter; the closed parameter set carries none, and the algorithm version `intraday-momentum-v1` is the label that yields `INCOMPATIBLE_VERSION`.
4. **Package version and digest.** The contract asks for a new prerelease and catalog digest; changing `PACKAGE_VERSION` would change the R17 catalog digest and every R17 result's metadata, which this slice must keep byte-identical, so `0.1.0a3` is unchanged (as for money flow). The momentum digest includes it.
5. **Evidence under `missing_input`.** R17 lists knowledge-excluded rows even for a missing-input operand; this contract requires none, so none are emitted.

## Author source validation

A standalone manual script (not committed, no test files added) built canonical bars for the 99 result fixtures (including the three prefix-property fixtures) and the 23 refusal fixtures and compared every value (R17 tolerance, `+0.0` where required), status, reasons, expected/observed counts and witnesses with the contract literals: 98 of 99 result fixtures matched as supplied and D04 matched after the +10 translation (point 1); all 23 refusals matched; no expected value was altered. Random series for all three families matched an independent exact-rational oracle within the R17 tolerance. A before/after snapshot of 4,320 R17 requests (EMA, RSI, ATR, bands, preparation views, refusals, `describe_intraday()` and its digest) was byte-identical. Strict typing was not run in this environment. `CONTRACT.json` is not amended here; the additive producer/header/unit amendment note remains owed.

See the [momentum API](../api/EF2_MOMENTUM.md). No acquisition, source rights, installed, cross-layer, performance or release claim follows from this source result.
