## Architecture and semantics

Diagnostics are separate optional consumers of accepted contracts/evidence; numerical kernels remain unchanged. Proposed allocation is pure `equity-feature-diagnostics` / `equity_feature_diagnostics` in canonical `packages/diagnostics`, experimental0.1.0a1 with exact inward contracts/evidence dependencies. EQ101 settles names/versions/schema/import boundary before EQ102 runtime Ready. No core dependency on diagnostics. External provenance bridges own actual adapter/worker object reading; pure code receives immutable typed facts. Reuse existing acquisition/generation identities instead of adding a catalog, scheduler, ledger or resolver.

Keep supplied market cutoff C, knowledge cutoff K, evaluation/decision E and optional real execution time separate. Ordinary market events obey the existing session rule; closing-auction and completed-bar exceptions retain existing definitions. `known_at <= K` equality is admitted; null is unknown, later consumed knowledge is an observed violation. K itself is an admission bound, not proof of acquisition. A mismatch between declared and requested K does not prove every consumed row was late. Reconstruction is labeled explicitly, not promoted to causal evidence.

Membership binds entity, universe/classification, effective half-open interval, decision knowledge, snapshot and revision. A current-only list is insufficient historical proof. Revisions preserve both effective and known-at facts; later corrections cannot replace historical content silently. Adjustment comparisons retain basis/policy/anchor/snapshot/currency and explicit scale compatibility; do not recompute adjustments or change accepted equations. Freshness requires a caller-selected age basis, target and tolerance. No hidden clock, inferred timestamp, current file time, automatic calendar or provider lookup.

Report each selected check independently as passed/failed/unknown with evidence coverage and reason. A nonrequested check is not a pass; an unknown prerequisite cannot be promoted to complete evidence. No universal leakage percentage/safety score. If a diagnostic fraction is useful later, bind exact numerator/denominator/assessed/unknown counts, deduplicate declared identities and represent zero denominator as not evaluated. Syntax/identity/version contradictions are typed validation errors, not silently converted to unknown facts. Advisory reporting never mutates calculation results. A strict caller admission decision must be explicitly selected and separately reported.
