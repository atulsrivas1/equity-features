# Conservative CI change classification

CI001 provides the internal stdlib tool `tools/ci_scope.py` and synthetic Git/event fixtures. It does not yet select which package workflows run. CI002 owns routing integration; until then all existing workflows continue to trigger.

The version1 [contract](stories/CI-001_CONTRACT.json) admits only three audited reader pages to DOCS after exact source binding and a complete committed diff. Other valid changes choose FULL. Invalid context returns valid=false/FULL/SOURCE_INVALID and CLIexit1, which cannot establish qualification. The CLI reads the runner event file and fixed GitHub context, emits a closed UTF8 JSON object with one LF, and performs no network/product import/build. Classification is not a hostile-author security boundary.

[Git raw diff documentation](https://git-scm.com/docs/git-diff#_raw_output_format) specifies raw record framing and submodule handling. The implementation consumes the entire NUL stream with full object identities and explicitly disables rename conversion, external diff/text conversion and submodule omission. Reader modifications must be existing regular UTF8 blobs without NUL. New/deleted/renamed/mode/gitlink/unknown changes stay FULL. A source-bound initial push is FULL with no comparative diff claim. Pull requests bind the exact two-parent merge to event base/source commits.

[Source audit](stories/CI-001_CONSUMER_AUDIT.json), [plan](stories/CI-001_PLAN.md), [actual validation](stories/CI-001_VALIDATION.json). Thirteen corrected author Windows fixture methods passed, including literal reader/nonreader, complete large diff, event/merge/source failure, Git index mode/nonUTF8 and CLI bytes tests. Earlier output failure, submodule red result, fixture setup error and provisional review are retained. The existing documentation workflow adds this fixture invocation for actual Ubuntu CI; no existing qualification step, trigger, matrix or permission is removed. Final exact source review, current hosted qualification and actual-main acceptance remain required. No package API/math/version/dependency or measured speedup claim.
