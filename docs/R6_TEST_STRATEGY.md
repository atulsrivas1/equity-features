Use the smallest meaningful independent fixture/probe that resolves each contract, plus retained regression and relevant integration suites. Performance experiments require new scope or an actual performance claim; no compulsory repeat of R5's162-sample benchmark for provider documentation. Numerical tests/acceptance and actual package installation cannot be waived by owner-authorized local review.

Public synthetic/mocked proof and actual authorized provider proof remain labeled separately. Required missing credentials/entitlements/terms/access/paid-download permission are explicit blockers, not skipped green gates. Continue independent authorized preparation or a dependency-satisfied story while the required input is obtained. No private pilot/month/annual generation is admitted by these tests; that requires its separate gates. Stop after accepted R6 before R7.
