## User control and evidence levels

Owner requires explicit user approval before any download and before any charge. Credentials, an installed adapter, a feature selection or an available endpoint authorize neither. EQ068 must bind consent to the provider, dataset/endpoint, instruments, time range, historical/live mode, request/row/byte limits and cost ceiling. An absent, unknown, expired or mismatched approval must fail before network acquisition. A zero cost ceiling cannot admit an unknown cost. Paid requests, subscriptions, batch jobs and automatic live reconnects cannot occur through fallback. Existing cached/local inputs do not authorize new acquisition. Approval grants no data redistribution rights.

The owner subsequently approved free qualification downloads only: free SDK/build dependencies and existing build artifacts/qualification CI are permitted without any billable operation. Provider market-data downloads, subscriptions, paid requests and charges remain unapproved. No provider SDK was installed or provider integration executed by this story. Exact optional dependency pins await actual qualification. The earlier blanket download restriction is preserved in the plan as decision history, with this narrow exception recorded explicitly.

Evidence classes are separate: public specification; literal synthetic conformance; installed SDK behavior; entitled account access; actual bounded provider integration. A declared AdapterCapabilities object proves none of the latter four by itself. The [accepted protocols](contracts/ADAPTERS.md) and [canonical fields](contracts/INPUTS.md) remain authority. Download, access, rights and numerical truth are independent gates.

## Canonical feature requirement decisions

TRADE supports trade count/volume/notional/VWAP/top-K only for explicitly eligible and correction-resolved population. TBBO only supports sampled quote states/spread; time-weighting needs qualified continuous QUOTE with supplied validity/coverage. BAR supports OHLC/volume/proxies; actual notional cannot be manufactured from close or rounded VWAP. Historical SMA/EMA/RSI/ATR/returns require governed DAILY slots/warm-up and action-compatible prior context. Intraday baselines need governed bucket grids. Relative/breadth need explicit benchmark/universe/sector inputs and compatible identity/session/cutoff; neither provider ticker endpoint supplies those guarantees automatically. Unknown known_at yields reconstruction-only acquisition facts, preserving the calculation's existing admission statuses.
