# I/O v1 specification ownership

[EQ123](https://github.com/atulsrivas1/equity-features/issues/280), E19 / R4.1 freezes the experimental publication design in the companion repository: [normative specification](https://github.com/atulsrivas1/equity-feature-io/blob/main/docs/contracts/IO_V1.md), [hand-worked protocol/scalar vectors](https://github.com/atulsrivas1/equity-feature-io/blob/main/docs/contracts/IO_V1_VECTORS.md), [manual complete-result wire golden](https://github.com/atulsrivas1/equity-feature-io/blob/main/docs/contracts/IO_V1_GOLDENS.json), [component PR3](https://github.com/atulsrivas1/equity-feature-io/pull/3).

Existing [acquisition protocols](contracts/ADAPTERS.md) and canonical inputs/results stay in equity-feature-contracts0.0.4a4. Companion source interfaces reuse them; separate sink interfaces consume complete canonical FeatureResult objects. Canonical schema1/mathv1, C/K/E timing, UTCns/scaled integer/null/structured output/quality/evidence/source and algorithm/config identities remain unchanged. I/O contracts depends inward on canonical contracts; pure calculations do not depend on I/O/workers/backends.

Protocol1/efio-json1/efio-key1/efio-content1 version admission, safe closed29-record/four-enum registry and exact float64 hex/string-integer JSON framing distinguish logical result SHA from physical artifact SHA. Complete zero-row results retain metadata and differ from absent results. Bounds and descriptors/counts bind complete ordered values/quality/metadata/evidence, including permitted partial structured outputs. Reservation/replay/conflict, commit/abort/lookup/read and unknown outcomes have explicit requirements; capabilities require actual backend qualification. Receipt replay is not worker exactly-once execution or financial/source certification.

EQ123 releases design documentation and independent expected fixtures. EQ124 implements factories; EQ125 implements runtime types/codec/lifecycle/conformance; EQ126/127 qualify Parquet/DuckDB backend semantics and resource/process/platform claims. No installed source/sink operation is advertised by this specification, and current foundation/adapter versions remain unchanged. [No-impact decision](decisions/IO_PUBLICATION_V1.md) and [pre-implementation plan](stories/EQ-123_PLAN.md) record this ownership boundary. R5 stays blocked by EQ130.

Review/current CI/actual-main publication/readback evidence lives on canonical280 and both linked PRs. Design vectors are not production sink tests or private qualification. No schema/formula/calculation algorithm version is changed; accepted R4 source/privacy/rights limits remain.
