No automatic replay of sent mutations or unknown ledger commits.

Ordinary logs receive identical supplied data/calculator/configuration/results and equivalent factual fields/artifacts/task instructions. Declare any trusted-head factor and give the baseline equivalent evidence; never manufacture an advantage by withholding information. Freeze expected findings before code and metrics before evaluation. EQ117 owner acceptance makes concrete thresholds binding; preparation does not accept them. Automated steps/time do not establish human usefulness or demand. Absent authorized participant feedback remains unknown.

Signatures do not establish truthful/complete logging or source authenticity. Witness readiness requires demonstrated need, reviewed protocol, actual independent retention/operator and permission together. No logical byte counter proves physical resource containment, hard cleanup deadlines or durability under arbitrary failure.
