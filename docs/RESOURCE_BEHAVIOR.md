## What is bounded

Bars retain fixed OHLC/totals/readiness and optional fixed prior context; trades retain fixed counters/checked sums/readiness. TopK retains at most configuredK original rows (1..10000); sampledquotes retain firstN observations (0..10000), fixed counters/exact spread/compensated bps. Structure retains one summary and omission flag per configured window plus whole-target summary. Continuousquotes retain cursor/current quote/original expiry, fixed durations/compensated sums and optional fixed seed; arbitrary merge is unsupported. No ingested raw chunk history or growing seen-ID set is retained; optional supplied fixed prior/seed context remains a separate owned input. Caller still certifies global nonretained identity uniqueness/source truth and serializes mutable accumulator access.

Bounds describe retained record dimensions, not constant total bytes. Configured windowcount, source/config/identifier sizes, optional fixed input context and numeric representation affect memory. Source/config objects can themselves grow; canonical input/chunk admission and backend copies scale with supplied rows. Caller-owned outputs and saved snapshots can accumulate arbitrarily if retained. Atomic update/snapshot/finalize clones a candidate while original exists; legal merge can hold two originals, candidate/result and bounded topK/observation unions. Diagnostics report three coexisting states, not an isolated transient allocation. Checked counters/sums preserve existing int64/decimal128/overflow-marker bounds; no accumulating unbounded recursive Fractions are saved. Public state text has its existing16MiB admission ceiling; digest is not authentication or arbitrary untrusted-state certification.

## Cancellation, batch limits and threading

Synchronous owned kernels expose no mid-call cancellation token, core batch-row budget or threadpool/budget. Unsupported `threads`/`cancelled` configuration parameters reject INVALID_CONFIG rather than silently influence calculations. The caller bounds/materializes chunks, checks cancellation between updates and may snapshot an explicitly certified consumed prefix. That preserves prior committed updates; it does not retract already consumed/yielded data or roll back an entire stream. Adapters/workers own acquisition/scheduling beyond core.

Actual synthetic external adapter checks AcquisitionRequest.max_rows/max_batches/max_batch_rows. Complete selection exceeding rows/chunks rejects SourceError(LIMIT) before yielding; Cancellation.is_cancelled true before acquisition yields CANCELLED with zero chunks, and a between-chunks cancellation preserves the already yielded chunk then raises CANCELLED. A caller-stop fixture snapshots count1 from an8trade declaration with honest prefixcertificate. Arbitrary source/cancellation callbacks may block or misbehave; these cases do not certify their resources/responsiveness.

Owned canonical reducers run with thread/process/subprocess creation entry points denied in the diagnostic; no hidden creation is observed. This is scoped runtime evidence plus the existing development boundary policy, not a sandbox or claim about all imported native backends/arbitrarycustom callbacks. Optional Arrow CPU/I/O settings and environment requests are caller-owned and demonstrated separately in [EQ041](BENCHMARKS.md); other effective pools/affinity are not promised. The library creates no scheduling service or automatic parallel worker, and the mutable accumulator has no concurrent-call guarantee.
