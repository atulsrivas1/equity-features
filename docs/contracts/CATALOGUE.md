# Where clients find input and output contracts

Clients looking up the input and output contracts of each feature producer should use the generated catalogue, not these core files directly:

- Python module: `equity_feature_io_contracts.catalogue` (package `equity-feature-io-contracts`).
- Docs path: `docs/contracts/catalogue/` in the `equity-feature-io` repo; start at [its CATALOGUE.md](https://github.com/atulsrivas1/equity-feature-io/blob/main/docs/contracts/CATALOGUE.md).

Core remains the authority: on conflict core wins.
