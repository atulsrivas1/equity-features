# Supplied typed content identity — EQ097

Experimental candidate `equity-feature-evidence==0.1.0a2`, CPython3.12; only dependency contracts0.0.4a4. [Normative format, complete35record field registry, limits and independent oracles](../stories/EQ-097_PLAN.md). Final source/installed bothOS/current artifact/main qualification establishes delivery separately.

`canonical_content(value)` returns bounded ASCII JSON bytes for an exact CanonicalBatch, FeatureResult or ConfigSpec. `content_chunks(value)` validates the entire immutable graph before its first yielded chunk, then returns chunks of at most65536bytes. It retains supplied content and performs separate prevalidation/encoding traversals without building a full projected tree. Materialization accumulates a full buffer and copies it to bytes. No decoder or dynamic type lookup is added.

`fingerprint_batch`, `fingerprint_result`, `fingerprint_config` stream complete typed-json-v1 bytes into SHA256 and return ContentFingerprint with actual domain/byte length. `verify_content(reference,value)` compares the entire recomputed fingerprint; valid mismatch returns false, malformed/unsupported/over-budget content raises EvidenceError. Missing columns and all-null columns differ; only batch column presentation is sorted. Row order and all result/quality/evidence/diagnostic facts remain bound. Int64 UTC/Decimal128 never convert through float; finite floats use exact hex with signed zero preserved.

`make_content_receipt(result,configuration,inputs,environment,execution,evidence)` accepts <=64concrete role/batch tuple pairs, validates whole configuration+inputs+result aggregate budgets before computing any fingerprint, verifies full metadata/kind/role/source/configuration/session/availability bindings, and derives actual formula versions/evidence count. It uses existing make_receipt after hashing all actual supplied content. `verify_receipt_content(receipt,configuration,inputs,result)` reconstructs these bindings and compares the receipt, returning false for valid content/binding mismatches. Existing make_receipt still binds supplied references without recomputing them.

Per content and aggregate receipt roots:32MiB encoded/1millionJSON key-value nodes/24containers;100000elements per stored tuple;64batch columns;256feature columns; metadata64inputs/256interval-coverage rows. All label/payload limits and exact edge semantics are normative in the plan. Errors expose fixed codes only. No file/network/clock/credentials/calculation/installation/publication occurs inside these helpers. Trusted local callers must preserve frozen inputs; Python reflection is not a sandbox.

[Actual synthetic producer example](../../examples/evidence_content.py) runs unchanged compute_trades and asserts3/10/1011/101.1/10/3, original full result/quality/metadata, then rejects same-metadata batch/output changes. Matching content hashes do not prove these inputs caused that execution. Environment/time/source rights remain caller assertions; source authentication, signing, mathematical certification and compliance are not claimed. Hashes are not privacy redaction.

[Cost protocol](../../examples/evidence_content_cost.py) measures1000/10000synthetic rows, three samples per materialization/hash-owned-bytes/stream fingerprint/full receipt operation, actual output parity and incremental traced Python peaks. Existing supplied input storage/precomputed result are excluded. Reports make no native/RSS/physical quota/deadline/speedup claim. BothOS installed combined-wheel results are required; current measurements are pending.
