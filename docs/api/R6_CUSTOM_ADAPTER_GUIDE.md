# Custom provider/file adapter guide — R6 draft

Prepared for [EQ074](https://github.com/atulsrivas1/equity-features/issues/83), reusing accepted [canonical protocol](../contracts/ADAPTERS.md), [conformance kit](../contracts/ADAPTER_KIT.md) and [I/O architecture](../IO_WORKER_ARCHITECTURE.md). This draft is not current R6 qualification. Actual installed/provider/release gates are retained in [EQ074 plan](../stories/EQ-074_PLAN.md).

## Start with an exact supported population

Define the source mapping before code: canonical kind, explicit provider→instrument/session IDs and calendar bounds, schema/precision, integer price coefficient scale/currency, integral quantity, eligibility/auction policy, adjustment evidence, original known-at, correction/coverage policy and immutable source/mapping/input revisions. Declare unsupported kinds/modes plainly. A ticker match, importable SDK, valid key or marketing endpoint is neither population compatibility nor permission to acquire. Fractional real shares cannot be rounded into the current integral-share contract. Vendor rounded VWAP cannot create exact actual_notional. Preserve unknown/future knowledge for existing C/K/E numerical admission.

Calculations accept supplied in-memory canonical contracts. Fetching/credentials/files/database/jobs/publication belong in your separate adapter/worker package. Reuse HistoricalAdapter, AdapterCapabilities, AcquisitionRequest and AdapterBatch; do not modify the numerical packages or invent parallel factory/receipt contracts. The accepted independently installable [source/sink extension example](https://github.com/atulsrivas1/equity-feature-io/tree/main/examples/third_party) supplies public method signatures, explicit registry/factory integration and literal numerical expectations. Its historic EQ128 acceptance is an example baseline, not a new provider certificate.

## Consent before credentials and acquisition

An application supplies exact scope-matched unexpired DownloadApproval with finite calls/rows/bytes/time/cost through accepted acquisition controls. Default deny absent/mismatched/expired scope and unknown/nonzero cost under budget0 before key lookup/client/request, including cost probes. Credentials are injected separately; public scalar config carries identities rather than keys, URLs or executable imports. Capabilities/config/factory construction must not acquire data. SDK construction protections do not sandbox arbitrary extension code: injected factories/transports/credential providers are trusted local code.

One authorization must allocate a cumulative budget across instances/requests. Fresh adapter creation does not grant more budget. Explicit retention approval is separate from download permission; default cache disabled. Retained data must bind source/mapping/snapshot/units/adjustment/availability/revision and rights expiry. No mutable latest/expired cache becomes an immutable revision. No retry/pagination/live reconnect/batch job/upgrade can occur through fallback. Stop at the approved endpoint/instrument/time/mode and limit; provider-boundary snapping must not widen acquisition.

## Deliver and validate actual outcomes

Emit finite bounded batches with request ID/ordinal/final/source binding, original source coverage and each chunk's exact delivery coverage. Preserve full canonical content, nulls, units, known-at and input scope. Distinguish missing/unavailable envelopes, observed successful zero-row batch, partial interruption and complete population. Do not sort/deduplicate/fill rows silently or certify completeness from EOF. Validate received data before selection/prefix delivery so malformed unselected rows do not disappear. Check cancellation/time between I/O/decoding/chunks, refresh blocking timeouts and charge failed partial bytes; declare logical limits separately from RSS/preemption.

Catch provider failures and raise fixed SourceError codes outside handlers so raw secret messages/causes/contexts do not escape. Do not put credentials in URLs or diagnostics. A debugger can access trusted process memory; public diagnostics are not a sandbox. Retain authentication/entitlement/rate-limit/transport/schema/unavailable/cancel/resource errors honestly rather than returning fabricated empty success.

Collect actual bounded adapter outcomes outside core, then use public validate_delivery and run_conformance. Cases require observed complete envelopes or an actually captured safe error; constructing an error-code fixture alone does not prove a real failure. Use independently chosen literal synthetic data, not implementation-generated expected values, and compare complete canonical/result/status/metadata/evidence/source identities. Include exact precision/overflow/order/duplicates, missing/empty/coverage, unknown/future knowledge, identity/session/adjustment/sampling mismatch, cancellation/limits and hostile failures. Source conformance does not establish data truth/rights/entitlement or arbitrary adapter resource safety.

## Installable qualification and rights

Package your adapter separately with py.typed, license/dependency metadata and explicit registration; keep optional provider SDK/codec dependencies out of core/default I/O. Build committed sources into repeatable wheel/sdist and install in fresh supported Windows/Linux CPython3.12 environments. Run public examples/tests outside repository imports, verify installed locations/strict public types/negative calls, and fingerprint core files before/after optional adapter installation. Read actual source/archives/ZIP digests/server expiry and attribution rather than trusting copied receipts. Downloads themselves require user authorization; this owner already permits free qualification artifacts/dependencies only, separately from the specific provider-data scope.

Use owned synthetic public fixtures; never publish keys, account diagnostics or private provider payloads. Library code license does not license market data. Actual bounded provider proof needs account-specific entitlement/rights/permitted retention/outputs and explicit scope/cost approval. Free exchange fees/credits/installed SDK do not prove zero delivery cost. Keep real proof distinct from mocks and package installs. Publish documentation and current evidence with the story, follow real lifecycle gates and stop before later-release/private generation scope.
