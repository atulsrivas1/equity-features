`write_bundle(receipt,configuration,result,inputs,publication)` verifies supplied
facts and emits deterministic bytes. `read_bundle(raw)` validates the closed
stored ZIP/manifest/content and returns immutable records. Explicit unavailable
refs are not content verified and have no resolver. No filesystem extraction,
source, path, URL, credential, callback or uploaded-code selector is accepted.
Numerical kernels are unchanged and remain independent of these I/O operations.

`equity_feature_bundles.replay.replay_bundle` checks all supplied actual content,
request work limits and fixed trusted installed versions before one calculator
invocation. Full canonical output bytes decide parity, including quality,
metadata and exact float64 spelling. Unavailable/incompatible/pre-entry-cancel
are distinct zero-call outcomes. The5s after-return gate withholds comparison
after a late return; it does not enforce active-call interruption or prompt
cleanup. No retries or new source acquisition. Replay reports never authenticate
original execution/environment or source rights and offer no safety score.

The bytes API owns no filesystem resources. A caller persisting an archive owns
its directory permissions, retention and nofollow cleanup. Publication is a
required caller declaration of synthetic data, not independent rights proof.
Application byte/node/row bounds are not physical OS quotas or latency claims.
Unknown schemas/versions refuse; extension requires explicit versioning and
renewed compatibility qualification. Directly constructed reports remain caller
statements; only actual observed control flow supports a replay observation.

Source implementation/development checks are candidate evidence only. Separate
local source/security/docs review, four fresh light/replay wheel/sdist forms on
Windows/Linux, complete current ZIP/source/RECORD/license maps and actual paired
