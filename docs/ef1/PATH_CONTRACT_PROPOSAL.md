## Scope, chronology and sampling

Let A=actual regular open, Z=actual regular close, C=market cutoff, K=knowledge cutoff. Gap requires A<C<=Z, path InputScope exactly[A,C). Drive duration positive int64, A+duration<=Z with wide addition checked before publishing; C>A. Let B=A+duration and T=min(C,B); drive path InputScope exactly[A,T). C<B independently contributes governed_gap/incomplete_coverage; C>=B uses exactly full[A,B), even if C>Z. Do not shift the scope end to C when C>B. All scopes must match session auction flags, use eligibility_policy supplied_path and metadata sampling none; no new context field.

All trade rows require A<=event_ns<T, even a closing-auction row at end when include_closing_auction=true. Endpoint/straddling/future rows reject BOUNDS, never silently filter. Opening-auction condition requires event=A and session include_opening_auction=true. Other closing-auction-conditioned rows reject BOUNDS (there is no admitted closing boundary in these half-open paths). Bars require A<=start<end<=T. Completed bar ending exactly T is admitted. Gaps between nonoverlapping bars are not inferred complete/incomplete by code; preserve explicitly supplied coverage.complete. Whole scope starts A, but first eligible row need not occur at A.

Canonical validate_batch(required_fields=()) applies to every row before filtering/readiness: original schema, int bounds, labels, ordered uniqueness, interval overlap and OHLC coherence remain required. Trade order strictly(event_ns,order_key), distinct event_id per entity. Equal event time and equal numeric price/size with distinct ascending keys/IDs is legal. Duplicate IDs/equal ordering keys reject DUPLICATE; reverse order rejects INVALID_ORDER. No sorting/deduplication/correction inference in library. Bar duplicate intervals and overlap reject under existing canonical rules.

TRADE candidates are eligible=true. Canonical validation rejects a PRESENT null or nonpositive price/size with INVALID_SCHEMA before readiness. An ABSENT required price/size column, if otherwise structurally valid, contributes missing_input/absent_input. This distinction never weakens the shared validator. Every such candidate is a sample; O is first candidate price, last is final candidate price. Ineligible rows are not operands and their unknown known_at does not block; they remain structurally validated and count as delivered population.

BAR candidate requires volume>0. Missing volume column or any null volume makes eligibility indeterminate and all outputs missing_input/absent_input or null_field, not a skipped row. Zero-volume rows do not supply O/samples; their price/knowledge payload is not a dependency, but existing structural validation still applies. Every positive-volume bar needs close; only first positive-volume bar additionally needs open as numerical operands. Existing canonical validation nevertheless rejects ANY PRESENT null/nonpositive OHLC field in a positive-volume BAR with INVALID_SCHEMA, including a nonfirst unused open/high/low. Only an ABSENT required operand column can contribute missing_input/absent_input where canonical validation otherwise permits it. Null volume retains the separately specified null_field eligibility uncertainty when other supplied facts are structurally valid. Nonfirst unused open/high/low/actual_notional are not numerical dependencies, but any supplied invalid unused cells still reject structurally before readiness. O=first candidate open; samples=all candidate closes. High/low never substitute for sampled extrema/hits; actual_notional is unnecessary.

## Original availability, coverage and scalar readiness

Every required selected market candidate, first bar opening witness (same row), and prior DAILY close requires original nonnull known_at<=K in BOTH known_at and reconstruction modes. Unknown=>unknown_availability; late=>future_knowledge. Selection is based on structural eligibility/time/order before knowledge, so a late/unknown earlier opening cannot be silently replaced by a later-known one. No generated availability timestamps. Calendar causal checks unchanged. Validate all present rows/bindings even when another prerequisite missing.

Path/prior namespace, instrument, PriceUnit currency/scale and AdjustmentSpec must equal config; path target session exact; prior session exception exact explicit preceding calendar slot. Ordering declared/duplicate_policy reject; coverage.observed=row_count. Prior source independent of path source is allowed; no invented same-source restriction. Prior scope uses supplied_path and exact session auction flags; close must be positive to be usable. Canonical validation precedes this operand readiness: supplied volume0 with nonnull close rejects INVALID_SCHEMA; supplied positive volume with present null close also rejects INVALID_SCHEMA. A present null close with volume absent or volume0 can be structurally valid and contributes missing_input/null_field; absent required close contributes missing_input/absent_input where otherwise structurally valid. A positive close with volume absent is permitted when canonical validation accepts the other original fields. Nonpositive close rejects INVALID_SCHEMA. DAILY OHLC/volume/actual_notional otherwise unused numerically, but every supplied cell retains existing canonical structural rules. Neither adapter nor library may drop an originally supplied volume/OHLC field to make a rejected row acceptable. No _admit_common target-session reuse for the prior row.

Path and prior completeness are required independently of causal eligibility. Coverage.complete=false=>governed_gap even if expected=observed. Missing batch=>absent_input. Present complete empty path or all noncandidates, with all other prerequisites ready=>all producer values null/not_applicable/no_eligible_observations. Incomplete or unknown required candidate operands never produce a current last/open/extremum/first-hit witness. Missing prior or proof wins readiness before zero-gap/no-sample mathematics. Drive unfinished prefix adds governed_gap even if delivered prefix coverage complete. Keep all independently applicable readiness reasons lexically sorted; missing_input wins incomplete_coverage. Missing/null/unknown/future use missing_input; governed_gap alone incomplete_coverage. Only after all readiness passes apply no-sample, then zero-gap, then no-hit statuses.

## Mathematics and quality population counts

Use integer coefficients/Fraction; convert each ratio to FLOAT64 once. Gap G=O-P. If G=0 all4 null/not_applicable/zero_denominator. Otherwise remaining=max(0,(last-P)/G) WITHOUT upper clamp; fill=max over samples clamp((O-x)/G,0,1); filled=exists sample (x-P)*G<=0; first_fill_ns=earliest such sample's event time (bar end). No hit=>filled=false available; first_fill_ns null/not_applicable/no_eligible_observations. Drive return=last/O-1, up=max(0,maxsample/O-1), down=max(0,1-minsample/O). Only completed drive is available.

QualityRow expected/observed preserve existing anchor's delivered-population meaning, not number of eligible/known/non-null operands. Every output depends on complete path universe to prove O and final/maximum/first identity; all gap outputs additionally require explicit prior slot. Thus identical count tuples are justified across each producer's output set. Let N=path.row_count if present else0; E=path.metadata.coverage.expected if present elseNone; R=1 if a valid-shape prior batch is present else0. Gap observed=checked_int64(N+R), expected=None if E=None else checked_int64(E+1). The extra expected1 is the explicit governed prior-close slot, never inferred market completeness. Drive observed=N, expected=E. Proof rows do NOT contribute numerical population counts; their own readiness still gates all values. Unknown expected propagates as None. Count overflow rejects OVERFLOW, even if another readiness failure exists.

A delivered prior row with null/late close still contributes1 observed, exactly as delivered null path rows count; readiness forbids availability. Observed counts never claim eligible/non-null/causal completion. O/last/extrema/first-hit overlap refers to the SAME source population and is not double-counted. Complete empty path has N=E=0: gap with ready prior expected=observed1 but null/no_eligible; drive expected=observed0 null/no_eligible. Missing path+present prior gives gap expectedNone/observed1; missing prior+three complete path rows gives4/3 missing_input/absent_input. First-fill absent uses same complete population counts as filled=false because proving no hit requires full universe.

Dependency map: gap remaining O,P,last; fill O,P,all samples; filled O,P,all samples; first_fill O,P,ordered complete samples. Drive return O,last; up O,all samples; down O,all samples. O and last require complete declared prefix to prove their identity; selected operand count is NOT Coverage.expected.

## Bounded deterministic selected evidence

Set metadata.evidence_limit=7 for gap,4 for drive. Emit only after common readiness, nonempty sample population, and (gap) nonzero G. These selected consumed witnesses accompany complete original bindings, not a complete path audit or proof of absence by a single row. No truncation: selection is defined and bounded before result construction.

Gap evidence association: remaining_fraction gets O,prior P,last (<=3); fill_fraction gets O,max-clamped-fill sample (<=2); filled gets earliest hit if present (<=1); first_fill_ns gets earliest hit if present (<=1). No hit =>no evidence for filled/first_fill. Drive return gets O,last (<=2); excursion_up gets earliest maximum sample (<=1); excursion_down gets earliest minimum sample (<=1), even if respective excursion clamps to0. Max-clamped gap fill ties choose earliest canonical sample, including multiple clamp1 overshoots. Equal-time ties choose existing order_key. Dedup per canonical key(entity,feature_id,input_id,row_id), not across feature IDs. Same-row O/last witness dedups once. Sort final evidence by existing FeatureResult canonical ordering; never put hash/input digest in place of source row identity.

TRADE row_id=original event_id, event_ns=original event_ns, known_at=original, boundary ordinary, effective bounds null. BAR row_id='bar:'+canonical decimal start+':'+canonical decimal end (no new source event ID invented), event_ns=original end for BOTH open/close operands, known_at original, effective bounds original start/end, boundary completed_interval. This row-level availability time avoids conflicting opening-start/closing-end evidence for the same canonical uniqueness key; O remains the bar.open operand, never a sampled start tick. DAILY row_id='daily:'+original prior session_id, event_ns=original end, known_at original, effective bounds actual start/end, boundary completed_interval. Reference calendar proof remains bound but does not consume the numerical selected-witness budget. No evidence when denominator/no-sample/incomplete/missing/causal failures leave mathematical identity unavailable.
