# Supplied reference classification and action admission

This opt-in EF1 subset implements the original five reference headers from the reviewed [contract](REFERENCE_CONTRACT_PROPOSAL.md) and its [source freeze](REFERENCE_SOURCE_AUTHORING_FREEZE.json). Source implementation and authored tests do not establish numerical acceptance. Local execution is pending resource admission; original official/reference-close and full EQ164 audit obligations remain open in EQ168/#508 and the EF1 release.

## Public calls and exact inputs

Use the unchanged `build_ef1_config`, `decode_ef1_context`, `ef1_definitions` and `compute_ef1(batches, config, entity=...)` in `equity_features.ef1`. Context producer is `reference_classification` or `reference_action`, calendar is null, and the config window contains only the target session. The target entity, source namespace, exact config digest, availability and full original input metadata are bound in the result. All producers return their complete lexically ordered header set.

Classification receives exactly `(classification_facts, classification_history, classification_projection)`. Action receives exactly `(market, action_facts, action_history, action_projection, source_representation, source_quantity_basis)`. Every slot is an actual immutable `CanonicalBatch` or `None`; a complete empty batch remains an actual binding. Omitted slots cannot be compressed, inferred from kind, or filled with a manufactured empty batch. References use mapping `ef1-reference-map1`. The action market accepts one TRADE, BAR or DAILY input.

EF1 discovery has additive non-transport `EF1Definition.alternative_requirements`, defaulting to `()`. Existing producers retain their requirements and empty alternatives. Classification has its three reference requirements and no alternatives. Action `.requirements` describes the five common reference roles; `.alternative_requirements` contains three **complete** legal six-role requirement sets, respectively market TRADE, BAR and DAILY followed by those same five references. A discovery consumer must choose exactly one complete alternative. They do not represent simultaneous market inputs, change the six runtime slots, or introduce a context selector. Canonical `InputRequirement`, registry definitions, codecs and default discovery are unchanged.

## Admission semantics

All original supplied rows are structurally validated before effective selection and knowledge assessment, including irrelevant/late rows. Canonical order and duplicate policies are enforced without repairs. Applicable membership/proof ambiguity is a typed `DUPLICATE` error before knowledge arbitration. Closed proof IDs decode canonical unpadded UTF8 base64url; actual target input, scope, publisher and revision relationships must agree. Invalid relationships are typed errors, including source disagreement in empty supplied proof populations.

Classification selects sector, industry or universe membership at the requested half-open effective query. An actual historical history proof and a complete projection of the full delivered facts are required. Actual complete zero facts prove membership absence; missing, unknown-count or incomplete facts do not. Null or blank original membership text is semantic `missing_text`. Nonblank text is returned unchanged, including spacing. The reviewed text envelope limits every original text to 128 codepoints and 512 UTF8 bytes and rejects C0, DEL and surrogates. Numerical payload on membership/proof rows is rejected; structurally legal all-null unused columns remain intact and bound. Canonical price-column unit requirements apply even when every supplied price is null.

Action computes declaration/history admission only. It never invokes the factor application utility or changes original prices, quantities, notional or dividends. `apply_factors` requires raw input adjustment/representation/quantity; `caller_transformed` requires actual adjustment equal to the requested policy, caller-transformed representation and requested quantity basis. An available gate makes no numeric field-readiness claim: absent optional market price/quantity columns alone cannot turn a valid declaration gate into a numeric feature result. Actual malformed fields, price units, scope, auctions and boundaries still reject.

Raw policy snapshot `none` is a sentinel and is not compared to actual coherent source snapshots. Raw selects no factor witnesses or factor knowledge dependencies, while every supplied factor still undergoes structural validation and remains bound. Actual action population and complete history/projection/source proofs are required even for raw. Nonraw required factors are supported boundaries in `scope_start < boundary <= anchor`; coherent requested-versus-actual action revision disagreement produces `revision_mismatch`. On apply-factors/nonraw paths, an actual BAR/DAILY interval straddling a required action boundary rejects; caller-transformed/raw paths perform no factor application.

Source representation/quantity proof applicability requires whole actual market scope containment and coverage of each original TRADE instant. A closing-auction trade equal to scope.end still requires event_ns < proof.effective_end; completed BAR/DAILY intervals retain end <= proof.end. This check precedes duplicate arbitration and knowledge, so an expired endpoint proof cannot compete with a covering proof or become consumed evidence. No endpoint arithmetic or overflow-prone end+1 is used.

All required active facts, market rows and proofs require original nonnull `known_at <= K` in both known-at and reconstruction modes. Evaluation time does not upgrade original knowledge. Irrelevant future-effective rows stay structurally validated and bound without causing a future-knowledge finding. Failed comparisons dominate unknown prerequisites, with scalar reason order exactly matching the frozen contract. State/reason assessments are available 1/1 values even when the assessment says failed or unknown.

## Quality and selected evidence

Classification value quality retains every independently applicable legacy reason in lexical order. Missing input/null/unknown/late/ineligible reasons take missing-input status priority over a simultaneous governed gap. Otherwise governed gaps are incomplete coverage, proved absence is not applicable, and a passed nonblank value is available. Counts sum the **full actual delivered** three-role populations with checked int64 arithmetic; expected is null when a role or its declared expected count is missing. Counts do not mean selected membership count or witness count.

Results retain all actual original input bindings in canonical lexical role order. Selected evidence is bounded and causal in both modes: original effective-start/event/known-at values are preserved; no excluded knowledge evidence or substitute timestamps are fabricated. Classification assessments may cite causal applicable membership/history/projection rows, while unavailable classification values have no witnesses. Its evidence limit is 9. The action limit is 12: each assessment cites causal applicable four proof roles and, only for nonraw, the actual first/last required factor rows deduplicated by original row identity. Market admission is bound through its original metadata and diagnostics, without market witnesses in this defined cap. Evidence is a selected explanation, not a full audit.
