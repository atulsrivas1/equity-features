## Numeric definitions

Scaled positive int64 input price p with scale s represents p/10^s currency per declared quantity unit. Conversion N/D means reference quantity units per continuous quantity unit, where N,D are positive int64. Normalize X=(p_c/10^s_c)*D/N and Y=p_r/10^s_r. Basis=X-Y; premium=(X-Y)/Y, a ratio rather than percent. Freeze deviations d_i=X_i-Y_held use the last reference market observation before F0 and all continuous observations in[F0,F1). Max=max(abs(d_i)); mean=sum(abs(d_i))/n, count weighted. Reopen gap=X_last_continuous_before_R-Y_first_reference_at_or_after_R and corresponding ratio gap/Y. The orientation is explicitly continuous minus reference.

Every intermediate rational is reduced, exact, with abs(numerator)<10^38 and0<denominator<10^38; zero is0/1. Check X,Y,difference,premium, each chronological absolute-deviation prefix sum and final division. Overflow raises ContractError(overflow), with no reorder, clipping or floating fallback. The freeze mean uses every admitted observation, never only topK. Stable topK sorts descending absolute deviation, then ascending(event_ns,order_key,observation_id). Int64 UTCns boundaries/ages, scales0..18 and strict nonbool integer admission remain exact. No measured performance or physical resource/deadline claim.

## Closed result quality

Fixed role order: continuous_coverage,reference_coverage,continuous,reference,continuous_feed,reference_feed,conversion. Each role holds a canonical ordered unique tuple of reasons and its consumed proof identities. A missing selected leg prevents dependent feed/conversion checks for that leg; do not invent a second absent mapping when no event exists to choose one. Unaffected independent roles are still assessed. Within each role reasons sort by this closed vocabulary order: incomplete_coverage,unknown_availability,future_knowledge,absent_observation,null_price,stale_observation,mismatch,absent_fact,unknown,stale,outage,not_live,not_scheduled_freeze,observed_empty. Identical reasons from repeated intervals are deduplicated; proof identities remain separately bound. Explicit state unknown/stale/outage remain distinct from absent_fact. State live when scheduled_freeze is required yields not_scheduled_freeze; scheduled_freeze when live is required yields not_live.

Any incomplete_coverage yields overall incomplete_coverage; otherwise any failed required role yields missing_input. All numerical values are null for these statuses, with available_at=null; preserve every applicable failed role. If all non-population prerequisites for freeze are ready and n=0, overall not_applicable with continuous:observed_empty,count0,empty topK,null metrics. No conversion is required or consumed for an empty freeze; supplied unused facts still undergo structural validation. Other complete zero-row selections yield absent_observation. Actual numeric zero is available.

Available or proven not_applicable available_at=max(all consumed original price/feed/conversion/coverage-known times,completed analysis end). Require available_at<=K<=E; unsupported causal configuration, including an analysis end beyondC orK, is invalid_config. Consumed proof identities include kind,role,ID/revision and exact interval/event. The full input digest binds unconsumed supplied records as well: changing a future record may preserve metrics while changing the input digest.

If none is known, the price role reports unknown_availability if any candidate has unknown time and future_knowledge if any is later thanK, in fixed reason order; report both if both occur.
