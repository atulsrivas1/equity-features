# EQ117 observation implementation contract

Qualification correction: the initial implementation confused a16,384-byte row bound with a useful operation-occurrence bound. Accepted canonical validation alone exceeded16,384 nested JSON calls during source qualification. The trace now permits at most1,000,000 actual occurrences compressed into at most4,096 ordered runs; every occurrence is still counted. The accepted16,384-byte row,65,536-byte worker output and64MiB aggregate capture limits remain unchanged and fail closed. These are capture implementation bounds fixed before the study, not changed performance/storage/benefit thresholds. The original failed captures remain evidence; no study observations were used to choose thresholds.

The accepted proposal `7405067b0360126a462bb7a66b5a89416cf93399843b0933b358760804e45073` is unchanged. This document specifies its observation implementation, not new thresholds. EQ117 is In progress; no scheduled observations have run.

The exact closed raw-row field set is `RAW_FIELDS` in `examples/evidence_evaluation_scoring.py`. Each row is canonical ASCII JSON plus LF, at most16,384 bytes. Status is `valid`, `failed` or `not_run`; every scheduled key `(os,case_id,arm,repetition)` occurs exactly once. The scorer refuses extras, duplicates, incomplete denominators, mixed source/run/environment/install identities and mismatched pair inputs. A valid diagnosis is compared against the complete independent literal native/configuration/strict-report projection using canonical JSON identity: boolean, integer and floating-point values are distinct. Failed/unrun slots count against correctness and budgets and are never silently excluded.

All stage, common-fixture and launch/import timestamps use actual `perf_counter_ns` integer endpoints in their respective process clock domains. A duration is `end-start`; endpoints are never subtracted across processes. The three arm stages include arm-specific preparation/serialization/storage, export and generic inspection/replay. Shared fixture production runs once per pair, is separately reported, and is added once to each arm's descriptive combined comparison. It is not run twice or hidden in an arm. Warm rows reference one launch/import duration per actor; actual CLI invocations are1 on its first request and0 on subsequent requests. Cold actors have one request each. These process-cold measurements are not filesystem-cache-cold claims.

Operation categories and selected API bindings are closed in `OPERATIONS`/`API_CATEGORIES`. The profiler records nested Python calls and `io.IOBase` stream boundaries, preserving an ordered run-length encoded `(category-index,api-index,repeat-count)` trace with positive counts. Its hash, API-name order, all API counters, category counters and total are cross-checked by the runner; the scorer independently validates counts/types/bindings. Calculator entries are counted at the actual accepted function and independently compared with replay-entry accounting. SQL C-internal calls, OS syscalls, physical I/O, human actions and total-machine resource use are not measured by these semantic counters. Optional improvement uses the ratio of the two five-trial arm medians; its20% decision uses exact integer cross multiplication.

Only the controlled producer and independent DATA scorer know case injections. The observer receives an opaque arm directory containing a common bundle/task/report/terminal plus its own ordinary log or event/ledger/export files. It receives no private producer seed, opposing arm, completion receipt or oracle. It checks the semantic graph and supplied terminal authority, not merely a hash-chain return. Original declared diagnostics remain distinct from recomputed retained-input diagnostics; absent retained input produces `UNKNOWN`. Advisory reports are declared/unverified. Same-owner model/terminal declarations establish no independent authenticity or execution proof.

Qualification tests are labeled controls, not study trials. They inspect full diagnoses, verify zero calculator entries for missing/corrupt inputs, reject changed graph context, test actual entry restoration, JSON type identity, schedules, nested instrumentation, real worker HELLO/EOF exit and injected-clock arithmetic. Fresh qualification builds/audits all eight unchanged distributions, repeats all archive builds and fully materializes selected SDists before wheel closure checks; only fresh wheel-compute installations are timed. Harness files reside outside the checkout and package sources. Parent and child use isolated interpreters and installed package origins/RECORD/dependency maps are checked before and after.

Push/PR CI qualifies the harness and never schedules the320-observation study. A separately reviewed fixed-head dispatch reserves one study ID; run attempt1 only, exclusive output roots, all failures and NOT_RUN rows retained. BothOS raw sets are combined without pooling timing strata. A failed or unfavorable study is reported, not replaced by a more favorable rerun. A later documentation-only results commit can reference that prior study only through an independently verified unchanged complete execution-input closure, explicitly listing every documentation difference and both heads. It cannot claim the full Git trees are identical.

The controller retains a full planned-row checkpoint before launching actors and after each slot. Cleanup observes actual EOF, waits, return codes and reader joins; unknown cleanup stops mutation and invalidates observations. Best-effort termination of a trusted owned launcher is not descendant containment or an unconditional cleanup guarantee. Partial checkpoints, bounded stdout/stderr prefixes and explicit failure markers remain evidence of failure, not completed observations. Closed regular-file sizes are logical bytes; nodes and unknown transient peaks are separate, not a total-physical-resource claim.

Automated outcomes do not establish human usefulness, demand or independent trust need. These remain `UNKNOWN`, with product decision `DEFER` and no selected conditional witness unless separately supported and decided.
