Closed kinds: `supplied_input`, `configuration_gate`, `structural_admission`, `operand`, `ordered_state`, `output`, `result_join`, `resource_admission`, `publication_owner`. Edge fields: `from`, `to`, `reason`, `contract`. Reasons: `configuration`, `structural_admission`, `operand_readiness`, `ordered_recurrence`, `compatible_witness`, `result_join`, `resource_admission`, `publication_owner`.

The selected union has one actual preparation closure. Its operand nodes describe anchored closes, successor true-range facts and last-N scheduled-slot moments when selected. EMA and RSI have separate chronological state/output nodes over compatible anchored close facts; ATR uses predecessor close and successor H/L with the accepted anchor-only warm-up exception. Bands share the exact unrounded moments/witness, with a position-specific denominator predicate. No numerical output is an invented prerequisite of another output. Complete selected output/result/global-evidence joining is a real node, followed by existing child/coordinator wire/resource checks and serialized publication ownership. These are descriptive execution boundary edges, not a new scheduler.

Validation rejects duplicate IDs/edges, unknown endpoint/reason/kind, cycles, malformed scope/hash and falsely qualified aliases. A development `GraphSpecificationError` has closed reasons `invalid_schema`, `duplicate`, `unknown_endpoint`, `cycle`, `source_mismatch`, `unqualified_callback`. It must not relabel original product errors or imply a sandbox. Expected graph edges/absent edges are authored independently before the builder.

## Tracing mechanism

Use one importable development `partition_entry` as the substituted supervisor partition call target, with the original function retained separately. Preserve each WorkItem's actual canonical built-in callback. Parent installs global module aliases once for the whole owned run; threads use bounded thread-local collectors. Spawn children import the development module and install/restore their own scoped hooks inside `partition_entry`; parent globals are not assumed inherited. Sequential execution uses the same delegated original partition implementation. Any call-site substitution is development-only and recorded in A/A provenance, not advertised as a production graph qualification change.

Before enabling hooks in each process, bind original task/scope labels and store object-ID→primitive-label maps; record that cost as tracing overhead. Hooks must never use hooked task/reuse/config digests or SDK codecs to label/serialize themselves. Use bounded bookkeeping suppression; tests distinguish nested real product calls from collector recursion. Trace sidecars use a separate unhooked serializer after the product scope, and never travel as an altered TaskExecution/publication payload.

Freeze the exact inspected alias inventory, not only definition names. Current read-only inventory identifies 19 function definitions across 26 loaded modules; it is not complete runtime coverage. Candidate function hooks: supervisor `_inputs`, `_size`, `partition_tasks`, `_validate_results`, `_admit_entities`; manifest `encode_task`, `_canonical`, `encode_output`; supplied `admit`, `result_identity`; worker intraday `_context`; actual intraday `prepare_intraday`/`compute_intraday`; SDK `prepare_publication`, `encode_result`, `decode_result`, `encode_receipt`, `publish`. Include all inspected exact-object module aliases used by selected production paths and assert their expected identity before installation. Property hooks: original TaskManifest task/reuse getters. Class method hooks: SerialPublisher submit/drain and actual selected sink lookup/read. Do not replace type-checked classes or recursively hook `_wire` per leaf. Additional dynamic/closure/caller aliases remain explicitly unobserved unless separately frozen and tested.

Diagnostics-on supervisor execution calls SerialPublisher `_submit`/`_drain` directly. Hook those actual private entrypoints in addition to public submit/drain; retain distinct outer and inner operation labels so one public call is not reported as two independent submissions. One-task diagnostics-on/off controls must assert the expected original product calls, encoded-byte counts and contained spans for both paths. The baseline benchmark uses diagnostics; public-only hooks would be incomplete. This feedback is a tracing-design correction, not a defect in original publication behavior.

Source-inferred counts (for example successful OutputManifest construction after its validator) are labeled inferred, not hooked counts. Returned-byte counters use actual byte results; `_size` contributes its returned size, while hash-string length is not task encoded length. Failed/rejected calls retain attempts, status and exception class; missing byte results are null, not zero. Preserve exact product return/exception behavior. Collector failure records an invalid trace without masking a product exception/return; harness retains the actual product outcome before rejecting attribution.

Each span has local process/thread/partition scope, optional prebound task label, parent ID, closed operation, start/end monotonic ns, returned/rejected status and optional returned-byte/size observation. Unknown task attribution remains explicit; do not fabricate per-task cost from partition totals. Record parent dispatch/result/join and actual component/shard membership. Exclusive ns subtracts the union of enclosed child intervals only on the same timeline. Never sum worker spans into wall makespan. Raw cross-process positioning needs qualified clock information plus actual parent/child handshake bounds; ambiguous ordering within the declared tick/bounds remains ambiguous. Unqualified clocks keep per-process durations and causal edges only.

Hard development bounds proposed: 131072 spans per owned sample, 32768 per thread collector, depth64, at most64 sidecar files, at most64MiB aggregate encoded trace bytes and16MiB per file. These are admission/reservation limits before collection, not just a post-hoc sum. Reserve16384 parent spans and8MiB parent bytes. Divide the remaining114688 spans/56MiB into deterministic allowances for actual planned delegate invocations: sequential uses one invocation per task; thread/process uses one per actual original partition. Each child/invocation gets floor(remaining/invocation_count) spans, additionally capped by32768/thread, and min(16MiB,floor(remaining_bytes/invocation_count)) bytes. Unused allowances do not silently transfer. Allocate at most one final plus one temporary sidecar per invocation and parent; original max16 tasks requires at most34 such files, within64. Include fixed metadata/summary records in the reserved byte allowance. Parent verifies exact reservation IDs, unique returned sidecars and aggregate closure. Reject unexpected invocations/background collectors, overflows or missing records; no atomic shared cross-process event counter is assumed. Thread contexts retain separate invocation reservations under one installed alias scope. Required tests exercise sequential multi-invocation, thread/spawn distributions and exact bound±1 cases.

Record actual event/byte/depth maxima; any missing/truncated/unterminated/recursive/inflated trace rejects attribution. Budget counters themselves use primitive bounded state. Reserve the full64MiB trace limit inside the unchanged1GiB measured job envelope. Actual object overhead is observed sampled RSS, not claimed equal to encoded trace bytes or physically enforced. A byte-limited writer must not first allocate an unlimited JSON representation; bound spans/fields and incremental serializer output before committing the sidecar. Retain a bounded rejection summary on overflow without replacing original calculation outcomes.
