Any call-site substitution is development-only and recorded in A/A provenance, not advertised as a production graph qualification change.

Before enabling hooks in each process, bind original task/scope labels and store object-ID→primitive-label maps; record that cost as tracing overhead. Hooks must never use hooked task/reuse/config digests or SDK codecs to label/serialize themselves. Use bounded bookkeeping suppression; tests distinguish nested real product calls from collector recursion. Spawn children bind received actual task labels before enabling their own product hooks.
