# EQ-135 - Measure onboarding feedback and verify C1 delivery

## Problem and value

The owner needs evidence about participation and a bounded next decision.

Parent: https://github.com/atulsrivas1/equity-features/issues/311
Release: R14 - Community onboarding and participation (C1). Provisional complexity: 3 points, not a time estimate.

## Plan before implementation

Freeze manual metrics before outreach: unique example attempts, useful feedback, first contributions, return participation and response times. Use one optional 30-day manually operated pilot; absent outreach authorization yields a prepared/deferred pilot with explicit reason.

## Acceptance

- [ ] Deliver a manual measurement sheet with definitions, initial baseline and evidence references; zero/unknown is reported honestly and no private participant details are published.
- [ ] Learning targets are five example users, three useful feedback reports and one returning contributor; missed targets do not invalidate artifact delivery and do not establish product failure.
- [ ] Record pilot outcome or explicit defer, actionable lessons and a bounded continue/change/stop decision; no scheduler or unbounded growth commitment.
- [ ] C1 receipt reconciles all seven stories, exact published documentation/artifacts, completed final-head reviews, checks and readback; R14/M5 only close after their own delivered scope qualifies.

EQ-131/132/133/134; SR-026/027; all existing-release gates; explicit authorization for any external invitations/posts.
