# Pure scanners over supplied features

EQ090#102 implementation candidate, experimental strategies0.1.0a1. Source review, runtime tests and fresh Windows/Linux artifacts remain pending; this is not release acceptance. The [accepted EQ089 contract](STRATEGY_LABEL_CONTRACTS.md) defines exact mathematics, fields, normalization and errors. Labels remain a separate future distribution.

`scan(StrategyRequest)` evaluates every supplied predicate and ranking cell. If any required cell is unavailable the row is unavailable, including when another predicate is false; otherwise a false predicate gives nonmatching, otherwise matching. Rows cover the complete declared universe, while ranked/selected contain matching entities only. Values compare in their exact represented int64/Float64 type, with no coercion or epsilon. Numeric direction followed by ascending Entity ties defines unique ordinal ranks. `top_k=0` is legal. Coverage is exact eligible/expected counts; empty0/0 has readiness empty_universe.

Use exact core `ValueType` members in mandatory `FeatureRequirement` fields. Each requirement binds feature/schema/algorithm/dtype/unit, accepted core config digest and complete input-semantic digest. Obtain expected config/semantics from the intended calculation specification and source policy before admitting candidate results; copying a candidate's claims does not establish compatibility or authenticity. Wrong horizons, baseline windows, adjustment/currency/source/eligibility policies reject inconsistent_identity rather than becoming missing observations. Actual missing cells retain absent_feature/absent_entity or their supplied core unavailable status.

Only session.trade.count, session.trade.volume, session.price.open_close_return, history.return and baseline.relative_volume are supported. Every supplied column is checked. Project unsupported producer columns into a separately valid core FeatureResult outside strategies, retaining matching quality, input bindings and relevant evidence. The [synthetic producer example](../../examples/research_scanner.py) computes real core trade features then explicitly projects count/volume; its independent expected count2/volume8 selects A. The scanner imports contracts and standard library only and never computes a substitute feature.

All public records are frozen. Concrete list/tuple inputs snapshot to tuples; request universe/results and complete content identities normalize harmless presentation permutations. Predicate order remains semantic. `encode`, `digest`, `feature_result_digest` and `input_semantic_digest` use explicit approved fields/types and tagged ASCII JSON; no decoder or file serializer exists. Full source values/nulls, quality/reasons, evidence and revisions bind content identity. Source snapshot/input revisions can preserve comparability and numeric selection while changing request/result identity. Metadata.identity_digest alone cannot establish content identity. Hashes bind equality and do not authenticate sources or conceal private inputs.

The package exports `Entity`, `FeatureRequirement`, `Predicate`, `Ranking`, `StrategyConfig`, `StrategyRequest`, `PredicateDisposition`, `StrategyRow`, `StrategyResult`, `InputSemantic`, `IntervalSemantic`, `StrategyError`, `scan`, `encode`, `digest`, `feature_result_digest`, `input_semantic_digest` and `__version__`. Config/request/result expose derived identity_digest properties. Closed StrategyError codes have fixed messages without caller payloads; errors constructing invalid core values remain core ContractError.

Source fixtures [test_strategies.py](../../tests/research/test_strategies.py) materialize [the published strategy requirements](../stories/EQ-089_FIXTURES.json) with independent expected statuses, ranking, selection, counts, semantic rejection and byte identities. Test method counts are distinct from fixture requirement counts. The [qualification builder](../../tools/build_research.py) requires exact committed package bytes (or documented Windows CRLF materialization), repeated identical six strategy/core archives, complete archive/RECORD/source maps, fresh wheel/sdist strategy-only imports and separate actual-producer execution with before/after core fingerprints. Artifacts live in dist/research, leaving the existing core six-artifact gate intact. Current evidence is tracked in [the validation ledger](../stories/EQ-090_VALIDATION.json).

No fetching, filesystem/database/network access, clocks, credentials, scheduling, publication, orders or portfolio state belongs in this package. Supplied facts and resource budgets remain caller responsibilities. Deterministic screening provides no profitability or tradability claim.
