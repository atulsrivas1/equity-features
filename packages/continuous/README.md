# Experimental continuous research contracts

`equity-feature-continuous0.1.0a1` supplies immutable, bounded data/config/result contracts and strict own JSON codecs. It depends only on `equity-feature-contracts0.0.4a4` and Python3.12. Existing core schemas, versions,39feature IDs and digests are unchanged; there is no automatic registry, Arrow/state, worker, MCP or receipt integration.

Inputs are caller-supplied raw positive scaled last trades, finite complete delivery scopes and original knowledge times, feed/product states and effective conversion facts. Same currency and declared underlying/quantity identities are required. The declarations do not authenticate economic equivalence, source completeness, provider rights or market truth. Calendars and DST partitions remain external supplied finite intervals.

`to_json` and the typed `config_from_json`, `input_from_json`, `result_from_json` codecs use closed own schema1 envelopes and separate config/input/result digests. `from_json` dispatches only these three own kinds. Canonical fractions are exact reduced witnesses, zero0/1. Missing knowledge/price is admitted data; it is distinct from malformed structure. Encoded/collection limits are logical representation limits, not whole-process physical memory, execution deadlines or a Python sandbox.

This version implements contracts/codecs only. Calculation kernels and six opt-in cross-venue feature IDs are a separate EQ114 delivery. Unsupported adjusted/FX/midpoint/official-close/duration-weighted/reconstructed/streaming modes are refused. No fetching, credentials, clocks, filesystem/database I/O, scheduling or publication occurs in this package. See the repository's EQ112 mathematics and independent literal fixtures, EQ113 API/build documentation and actual release evidence before relying on a qualified installation.
