# Equity Feature Conformance

Experimental pure comparison harness for supplied point-in-time diagnostic declarations and result-content fingerprints. `check_diagnostics` invokes the accepted public evaluator, `compare_content` compares supplied scalar fingerprints, and `summarize` aggregates ordinary test outcomes. A matched unknown assertion remains unknown. No report certifies source truth, historical consumption, universal leak detection or execution authority.

Required: Python3.12, contracts0.0.4a5, evidence0.1.0a3 and diagnostics0.1.0a2. Calculators, adapters, storage, workers and native dependencies are separate integration costs. No callbacks, acquisition, serialization or I/O in this runner. See the repository's EQ104 plan/API and synthetic installed examples for exact supported classes and work bounds. Initial source implementation is not release qualification.
